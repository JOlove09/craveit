# CraveIt 🍜
### Discover. Cook. Enjoy.

**CraveIt** is a modern Asian cuisine recipe explorer built with React.js. Discover delicious recipes from different Asian countries, explore ingredients, and follow step-by-step cooking instructions.

## Features

- Explore 80+ curated Asian recipes
- Discover cuisines from India, Korea, Japan, China, Thailand, Vietnam, Malaysia, and the Philippines
- Search recipes by name
- Filter recipes by cuisine and dietary preferences
- View ingredients and cooking instructions
- Browse a responsive, user-friendly interface
- Fetch additional recipes using a public REST API

## Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Styling:** Bootstrap 5
- **Build Tool:** Vite
- **Routing:** React Router
- **API:** DummyJSON Recipes API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/JOlove09/craveit.git
cd craveit
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
